# Typewriter-
轻量简单的脚本工具，用来针对那些禁用粘贴的网页（例如Pintia），将想要粘贴的文本放在文本框，直接按下快捷键或是按钮即可代替手打输入长代码或文本。A lightweight and simple script tool designed for scenarios where paste is disabled on certain websites (such as Pintia). paste the text you want into the input box, then press the assigned hotkey or click the button to simulate typing and input the content automatically.
